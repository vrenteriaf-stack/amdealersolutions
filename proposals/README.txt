AM Dealer Solutions — Mathieu Ford deck (Nov 9, 2026)

Upload this whole "mathieu-ford" folder into the folder that serves
deck.amdealersolutions.com (its Document Root in cPanel > Domains),
next to the main deck's files. Don't touch the main deck's files.

The deck will then open at:  https://deck.amdealersolutions.com/mathieu-ford/

  index.html          opens the deck
  mathieu-ford.html   the Mathieu Ford deck
  .htaccess           stops browsers from showing an old cached copy
                      (hidden file: in cPanel File Manager turn on
                      Settings > "Show Hidden Files" to see it)

The deck also works on its own: you can email mathieu-ford.html as an
attachment and it opens in any browser.
